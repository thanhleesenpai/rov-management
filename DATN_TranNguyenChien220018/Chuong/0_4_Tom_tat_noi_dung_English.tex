\begin{center}
    \Large{\textbf{ABSTRACT}}\\
\end{center}
\vspace{1cm}
Remotely Operated Vehicles (ROVs) are widely used for underwater surveying, monitoring, and manipulation tasks in environments where GPS signals are unavailable, visibility is limited, and vehicle motion is significantly affected by water currents. Existing approaches mainly include manual control, sensor-based stabilization, and computer vision-based control. However, manual operation depends heavily on the operator’s skills, specialized navigation sensors are often costly, and vision-based methods can be affected by variations in underwater lighting and water turbidity. Therefore, this graduation project adopts an integrated software-based approach for controlling and managing an ROV by combining multiple data sources to improve operational stability, monitoring capability, and mission data management. The proposed solution consists of a Ground Control Station (GCS) deployed at the topside station and a Web-based management platform. The GCS enables operators to control the ROV using a joystick, adjust its movement speed, operate the gripper, and control the lighting system. It also displays real-time video, heading, depth, temperature, humidity, and battery level. The system supports automatic heading hold, depth hold, DVL-based position hold, and position hold using a vision-based algorithm. In addition, it provides video recording, sonar-based visualization of the surrounding environment, and mission logging, including operating time, travelled distance, and trajectory derived from DVL data. The Web platform receives and stores mission data for subsequent management and retrieval, while also integrating a YOLO-based object detection algorithm. The subsea ROV, including its embedded computer, sensors, and actuators, serves as the hardware platform and is not the primary design scope of this project. The main contribution of the project is the development of an integrated software architecture that combines manual control, automatic stabilization, real-time monitoring, mission data management, and object detection, thereby improving the intuitiveness, safety, and effectiveness of ROV operations.
